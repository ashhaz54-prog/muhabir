Muhabir is a Chrome extension for correcting and improving Arabic text. This policy explains what data the extension handles and how it is used.

What Muhabir does

  • Local Arabic fixing features that run inside the extension and do not require an external AI service.
  • AI-powered side-panel services (Summarizing, Tashkeel, etc.) which require an OpenRouter API key supplied by the user.

Data handled

  • Text that the user explicitly selects or submits for processing.
  • The user's OpenRouter API key (stored locally).
  • Local preferences (theme, model selection, etc.).

How data is used

Local features

Text is processed locally inside the extension. No data is sent to our servers.

AI-powered services

Submitted text is sent to OpenRouter only after the user provides an API key and triggers the service. Muhabir does not sell user text or use it for advertising.

Storage

Data is stored locally in Chrome storage. The API key is not uploaded to a Muhabir backend as we do not operate one.

User control

  • Avoid AI processing by using local-only features.
  • Remove your API key from settings at any time.
  • Clear local browser data to reset the extension.

"مُحَبِّر" هو ملحق لمتصفح كروم مخصص لتصحيح وتحسين النصوص العربية. توضح هذه السياسة ماهية البيانات التي تتعامل معها الإضافة وكيفية استخدامها.

ماذا تفعل الإضافة

  • ميزات الإصلاح المحلي التي تعمل داخل الإضافة ولا تتطلب خدمة ذكاء اصطناعي خارجية.
  • خدمات اللوحة الجانبية المعتمدة على الذكاء الاصطناعي (مثل التلخيص، التشكيل، إلخ) والتي تتطلب مفتاح OpenRouter API يضيفه المستخدم بنفسه.

البيانات التي يتم التعامل معها

  • النصوص التي يختارها المستخدم أو يرسلها للمعالجة بشكل صريح.
  • مفتاح OpenRouter API الخاص بالمستخدم (يُخزن محلياً).
  • التفضيلات المحلية (المظهر، اختيار النموذج، إلخ).

كيفية استخدام البيانات

الميزات المحلية

تتم معالجة النصوص محلياً داخل الإضافة. لا يتم إرسال أي بيانات إلى خوادمنا.

خدمات الذكاء الاصطناعي

يتم إرسال النص إلى OpenRouter فقط بعد تزويد المفتاح وتشغيل الخدمة من قبل المستخدم. لا يقوم "مُحَبِّر" ببيع نصوص المستخدمين أو استخدامها للإعلانات.

التخزين

تُخزن البيانات محلياً في مساحة تخزين المتصفح. لا يتم رفع مفتاح API إلى خادم خلفي، حيث أننا لا نشغل أي خوادم خلفية حالياً.

تحكم المستخدم

  • تجنب معالجة الذكاء الاصطناعي عبر استخدام الميزات المحلية فقط.
  • إزالة مفتاح API من إعدادات الإضافة في أي وقت.
  • مسح بيانات المتصفح المحلية لإعادة ضبط الإضافة.
