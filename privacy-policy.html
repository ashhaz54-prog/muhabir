Chrome Extension Privacy Policy

Privacy Policy

Last updated: April 7, 2026

Muhabir is a Chrome extension for correcting and improving Arabic text. This policy explains what data the extension handles and how it is used.

What Muhabir does

Muhabir offers two categories of features:

  • Local Arabic fixing features that run inside the extension and do not require an external AI service.
  • AI-powered side-panel services, such as proofreading, summarizing, simplifying, replying, and adding tashkeel, which require an OpenRouter API key supplied by the user.

Data handled by the extension

Muhabir may handle the following data:

  • Text that the user explicitly selects, pastes, or submits for processing.
  • The user's OpenRouter API key, if the user chooses to configure it.
  • Local extension preferences such as fix mode, bullet style, selected AI service, theme, and model selection.
  • Temporary metadata required to move selected text from the active page into the side panel.

How data is used

Local features

When the user uses the local Arabic fixing features, text is processed locally inside the extension.

AI-powered services

When the user uses AI-powered services in the side panel, the submitted text is sent to OpenRouter so the requested AI operation can be completed. These requests are made only after the user provides an OpenRouter API key and actively runs the service.

Muhabir does not sell the user's text. Muhabir does not use submitted text for advertising.

Storage

Muhabir stores certain data locally in Chrome storage, including:

  • The user’s OpenRouter API key
  • Extension settings and preferences
  • Temporary side-panel state

This data is stored so the extension can function across sessions. The API key is stored locally by the extension and is not uploaded to a Muhabir backend, because Muhabir currently does not operate a production account backend.

Third-party services

Muhabir currently integrates with:

  • OpenRouter: https://openrouter.ai/

If the user chooses to use AI-powered services, their text and API request metadata may be handled by OpenRouter under OpenRouter’s own terms and privacy practices.

Data sharing

Muhabir does not share user data with third parties except as needed to complete an AI-powered request that the user explicitly initiates through OpenRouter-backed features.

User control

Users can:

  • Avoid AI processing entirely by using local-only features
  • Remove their OpenRouter API key from the extension settings
  • Clear extension storage by removing the extension or resetting local browser data

Contact

For questions about privacy or data handling, use the support or feedback links provided by the extension listing.
